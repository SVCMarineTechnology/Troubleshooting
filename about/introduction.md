# About

This repo serves as the central home for creating, maintaining, and publishing troubleshooting guides for the Marine Maintenance Technology Program.  It’s designed to provide a durable, professional workflow for technical documentation, built around three core goals:

- **Common File Format** - All troubleshooting guides are written in a widely adopted, human‑readable format that supports rich content and is easy for contributors to learn and use.
- **Version-controlled Storage** - Every guide is stored in a cloud‑backed system that tracks changes, tracks history, supports review/approval, and ensures accountability for all updates.
- **Simple hosting model** - The repository automatically transforms guides into HTML *and* hosts them online, making it easy for students and instructors to access the latest content.

The following technologies were chosen to meet these goals:

- [Markdown](https://en.wikipedia.org/wiki/Markdown) - Markdown was chosen as the underlying format for the troubleshooting guides. Markdown is a lightweight markup language designed to make writing for the web more natural and readable in plain text. Markdown is a widely used tool for publishing written content across the Internet.
- [GitHub](https://github.com/) - GitHub is a platform where millions of developers collaborate, and create content together. It hosts over 420 million repositories and is used by more than 150 million people to securely store content, track changes, and manage updates via built-in approval workflows.
- [DocFX](https://dotnet.github.io/docfx/) - DocFX is a static documentation generator that takes Markdown files and turns them into a full static website.  GitHub has features for using DocFX to automatically transform Markdown files in a repo into HTML *and* hosting that content on the Internet.

Detail on exactly how this repo was built to achieve these goals can be found here: [How this repo was created](how-to-create-repo.md).
