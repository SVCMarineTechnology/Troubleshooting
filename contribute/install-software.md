# Install Software

Before you can start working with this repo, you'll need to install these components on your workstation:

- **Git** - This is the tool you'll use to clone and work with the [Troubleshooting](https://github.com/SVCMarineTechnology/Troubleshooting) repo.
- **DocFX** - This is the tool we're using to transform our markdown files into HTML.  You need to install this locally so that you can verify that your files successfully render before merging them.

Additionally, there's some optional software that's suggested:

- **Visual Studio Code** - A lightweight editor that's useful for editing configuration files as well as merging changes.
- **Typora** - This is the markdown editor used to create much of the content in this repo.  You can use whatever editor you like.  So if you prefer a different tool, you can skip the Typora installation procedure.

The installation procedures vary depending on the platform you're using:

- [Install Software On Windows](install-windows.md) - How to install the software on Windows
- [Install Software on Mac](install-mac.md) - How to install the software on a Mac

Click the link for your platform and complete the procedures on that page.
